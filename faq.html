AI & keys

Do I need an API key?
For real AI logging, yes — OpenRouter sign-in, or a key for Gemini / OpenAI / Ollama Cloud. Local Ollama needs a reachable URL. Without a provider, the offline simulator still demos the UI.
Which provider should I pick?
OpenRouter is easiest for free vision models. Gemini if you have a Google AI Studio key. Ollama for local / LAN. OpenAI for direct gpt-4o access (paid).
What does Auto failover do?
On failure it tries other keys/models on the same provider — it never jumps platforms for you.

Logging & accuracy

How accurate are calorie estimates?
They’re model estimates, not lab measurements — especially for mixed Indian plates. Always review weights. Weigh ingredients when precision matters.
Can I edit a meal or workout later?
Yes. Open it from the day log. Meals support live macro rescale; workouts support sets/reps/weight and AI session names.
Barcode not found?
Lookups use Open Food Facts after on-device decode. Regional products may be missing — describe the food instead.
What does “Monthly” mean on Progress?
A rolling 30-day window ending on the day you select — not a calendar month.

Reminders

How do daily reminders work?
Settings → Daily log reminder. Allow notifications; for timely delivery also allow Alarms & reminders.

Backups

Is cloud backup encrypted?
Yes — AES-256-GCM on-device before upload. See Encryption.
I forgot my backup password
There is no recovery. That’s the point of zero-knowledge encryption. Keep a copy of the password somewhere safe.

Updates

F-Droid vs GitHub APK?
Same codebase, different signing keys. Don’t install one over the other expecting a seamless update — pick a channel and stay on it.
How do GitHub updates work?
Update checks open the APK download in your browser. FitBuddy does not sideload installers itself.
